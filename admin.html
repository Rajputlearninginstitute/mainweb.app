Admin sign in

Use the email and password created in your Firebase Authentication console.

Firebase setup is required before sign-in will work.
Security note: Firebase sign-in alone is not enough. Add the signed-in UID to the Firestore admins collection and deploy the included firestore.rules file before using this panel.
